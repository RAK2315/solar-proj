### What the twin mockup established

- The real `CameraRig` parks behind the drone pad until a mission flies, so the twin
  needs its own default camera. What worked at 1366×768: look at `(0, 0, 38)`,
  height 84, 84 back on +z, vertical fov 58, a slow sway of ±0.3 rad **derived from
  `siteSeconds`**, not from a clock of its own.
- `PanelField` draws every array one colour. The mockup laid a thin unlit box over
  each non-healthy array, coloured from the ramp. P1 should do this natively with
  per-instance colour.
- In a narrow box the field's width is cropped because the lens is fixed
  vertically; the mockup pulled the camera back by `max(1, 1.5 / aspect)`. Below
  about 320 px wide the field is too small to read, so do not dock the twin that thin.
- The scene as built is a **daylit desert**. `06-design-system.md` §7 describes a
  near-black ground. Dark mode needs a second environment: void background and fog,
  a `#0b1018` ground, a cool directional light at about 2.6 and a hemisphere light
  at about 1.2 gave arrays that read as desaturated blue.
- DOM labels were tied to arrays by projecting `arrayCentre(id)` in a `useFrame` and
  writing a `transform` straight to the element. No React state, nothing re-renders.

## Traps that cost time this session

- **A hook rewrites every Bash call** (`rtk`). Two consequences. A heredoc whose body
  contains `||` gets cut in half, so write multi-line patch scripts to a file and run
  the file. And auto mode sometimes returns "no verdict" on the first try because
  the input changed under it; issuing the same call once more goes through.
- **Background servers get killed when memory runs short.** `next start` in the
  background was reaped while idle. If a page will not load, check the port before
  debugging the code.
- **Two build paths.** `npx next build` skips the gate and takes about a minute:
  use it to iterate. `npm run build` runs the whole gate and takes about four: use
  it to verify. Kill port 3000 and wipe `.next` before either.
- **`waitForSelector('canvas')` waits for a visible canvas.** A canvas inside a
  hidden box times out; pass `{ state: 'attached' }`.
- **A `backdrop-filter` traps `position: fixed` children.** Recorded in the design
  doc, repeated here because it looks exactly like a layout bug.
- **Focusing a control that is partly off-screen scrolls an `overflow: hidden`
  ancestor.** A screenshot then shows the whole page shifted. `overflow: clip` stops it.
