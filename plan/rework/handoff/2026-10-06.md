### What the hazards are for (the owner asked; this is the answer they accepted)

crack repairs, and re-solves the crew day. A cloud is a shortfall that is weather

**Write this into `03-features.md` before any code.**

- **Data:** InfraredSolarModules. Read the class list and the image size from the
  dataset's own metadata file. Do not trust memory or the plan. Fix the class order

## Traps that cost time this session

- **A hook rewrites every Bash call**, and a heredoc with JSX, backticks or `||` in
  it gets cut and fails to parse. Write patch scripts with the Write tool into
  `%TEMP%` and run them with `node`. Half the files are CRLF and half LF, so do
  replacements line-ending agnostically and fail loudly on a missing target.
- **The detector needs daylight.** It returned nothing under the dark-styled scene.
  If detection goes quiet after the 3D restyle in A.9, check the lighting first.
- **The detector's crop assumes the mission camera.** `moduleRoi` is only right
  while a flight is followed. Changing the camera or the module geometry in A.9
  can move the module out of the crop: re-check a real inspection in Chrome.
- **`.sy p, .sy dl, .sy ol` reset padding.** Anything of those types that needs
  padding must be selected as `.sy .name`.
- **Rebuilding under a running `next start` serves the old chunks.** Kill the port,
  wipe `.next`, run `node scripts/sync_artefacts.mjs`, build, serve. `npx next
  build` skips the gate and the sync; `npm run build` runs both.
- **Frame rate has to be measured in a visible Chrome window.**
- **The Groq free tier rate-limits quickly.** A few direct calls to `/api/triage`
  are enough to trip it, so do not hammer the route while testing the backoff.
