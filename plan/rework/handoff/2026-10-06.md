## Traps that cost time this session

- **A hook rewrites every Bash call**, and a heredoc with JSX, backticks or `||` in
  it gets cut and fails to parse. Write patch scripts with the Write tool into
  `%TEMP%` and run them with `node`. A small helper that does exact, line-ending
  agnostic replacement and throws when a target is missing saved a lot of
  re-reading: half the files here are CRLF and half are LF.
- **The detector needs daylight.** It returned nothing on the textured module under
  the dark-styled scene. The twin now draws the daylit scene whenever a flight is
  followed. If detection ever goes quiet again, look at the lighting before the crop.
- **The crop is computed for the mission camera.** `moduleRoi` assumes the camera is
  where `cameraAt` says. It only is while the flight is being followed, so sampling
  is gated on `followFlight`, and waits a second after the lock for the lerp.
- **An absolutely positioned `dl` lost its padding** to the scoped reset
  (`.sy dl { padding: 0 }`). Anything that is a `p`, `dl`, `ol`, `ul` or heading and
  needs padding has to be selected as `.sy .name`.
- **`appearance: none` on every input hid the range slider's track.** Restored for
  `input[type=range]` only.
- **Rebuilding under a running `next start` still serves the old chunks.** Kill the
  port, wipe `.next`, build, serve. `npx next build` skips the gate; `npm run build`
  runs it.
- **Frame rate has to be measured in a visible Chrome window.** Headless on a
  software renderer measures the software renderer. `npm run measure:hero` does it.
