## Traps that cost time this session

- **`route.ts` and `triage.ts` are CRLF**, most of `src/` is LF. A patch that
  matches on `\n` fails on those two.
- **Escaping a script through the shell mangles it.** Write patch scripts with
  the Write tool and run them with `node`.
- **`next build` lints test files harder than `npm run lint` does.** A variable
  named `module` in a test passed lint and failed the build.
- **A test runner's clock is not a browser's.** The solver's correctness tests
  pass an explicit budget; only the tests of the limit use the real 50 ms.
- **At 600x the flight camera lags its spline**, so a harness that flies at 600x
  captures the wrong frame for the detector. Verify detection at 60x.
- **A canvas is 300 by 150 for an instant after it is attached.** `check:layout`
  waits for it to be sized.
- **Two CSS rules of equal specificity are decided by order.** The side layout's
  queue rules sit below the sandbox's and won until the sandbox's were raised.
